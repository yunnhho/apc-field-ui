**4) 정한 기준값**

- 정지 권고 3분(`StopRecommendMinutes = 3`), 행거 90초 간격(`ConveyorSeconds = 90`). 최대값은 하한 이탈이면 최소.
- 기준 시각 2026-11-26 14:52:30.

**확인 질문**

*정한 기준값*
1. 전처리·프라이머 관리 범위를 베이스·클리어와 같게 했습니다. 부스별로 따로 둘까요?
2. 정지 권고 3분은 이탈 시작 기준으로, 3분 정각부터 권고로 했습니다. 3분 초과부터로 할까요?

*해석*
3. "경계 10% 안쪽"을 관리 범위 폭의 10 %로 했습니다. 기준값(공칭) 대비 10 %로 할까요?
4. 판정판은 라인 전체 기준으로 했습니다(이탈 > 주의 > 정상). 선택한 부스 기준으로 할까요?
5. "이탈 중 투입된 행거 강조"는 "영향 없음"으로 닫히지 않은 행(진행 중, 조치 필요, 재도장, 추가 검사)에 했습니다. 모든 이탈 행에 강조할까요?
6. 막는 동작은 "진행 중 이탈에 영향 없음 등록"만으로 봤습니다. 라인 투입 자체를 막는 신호도 화면에서 낼까요? 지금은 권고 문구만 있습니다.

*배치*
7. 판정판 → 부스 타일 → 투입 정보 → 값 카드 → 추이 → 이력 순으로 했습니다. 이력 표를 추이보다 위에 둘까요?

*데이터 모양*
8. 행거 번호(H-0640), Lot(CL-1126-02), 색상 코드(NH-883P), 확인자 이름과 오븐 정지 상태는 제가 만든 값입니다. 이 형식과 항목이 맞나요? 이탈 항목의 "예상 불량" 문구(백화·먼지 부착 등)도 제가 정한 것입니다.

**5) 지침 모호점**
- 판정판 대상(라인 전체/선택 부스) 지침 없음 → 4번.
- "눈에 띄게" vs 행 배경색 금지 → 셀 글자색·굵기(5번).
- 타일 이름만 vs 상태 단어 요청 → 타일 `Text`에 단어.
- 값 없는 오븐 카드: 값 빈칸, Footer에만 "관리 안 함".
- 하한 이탈의 "최대값" 지침 없음.
- `ApcInfoStrip`을 `Columns` 칸에 넣을 때 높이 지침 없음 → S(44).
