# 확인 질문 시연 (D1, 1회) — 다음 세션 진행용

목적: SKILL.md 6장 4단계 "확인 질문"(main `5ddcc53`)이 실제로 쓸 만한 질문을 내놓는지 확인한다.

## 진행
1. 설치본이 저장소와 같은지 맞춘다: `bash tools/install-skill.sh`
2. `D1-paintbooth/PROMPT.md` 내용을 그대로 프롬프트로 하여 Sonnet 에이전트 1개(general-purpose, model sonnet)를 띄운다.
   - 프롬프트는 1126 D1과 경로만 다르다. 보고 항목 1)~5)에 "확인 질문"을 일부러 넣지 않았다 — 스킬만으로 질문 목록이 나오는지 보는 시험이다.
   - 프롬프트에 "사용자에게 질문할 수 없다"가 있으므로 질문은 보고의 "확인 질문" 목록으로 나와야 한다.
3. 에이전트 보고를 `D1-paintbooth/REPORT.md`로 저장한다(하위 에이전트는 파일 쓰기가 막힘).
4. PNG 확인 후 평가.

## 평가 기준
- 보고에 "확인 질문" 목록이 있는가(없으면 스킬 지시가 안 먹힌 것)
- 4묶음(정한 기준값 / 해석 / 배치 / 데이터 모양)으로 나뉘었는가, 최대 8개, 막기·판정 규칙이 먼저인가
- 질문마다 "만든 것 + 다른 안"이 있어 예/아니요로 답할 수 있는가
- 1126 D1 1차·재시연에서 에이전트가 스스로 정한 것이 질문으로 나왔는가:
  - 전처리·프라이머 관리 범위(요구에 없음)
  - "경계 10% 안쪽" = 관리 폭의 10%로 해석
  - "영향 행거 눈에 띄게"가 모든 행에 해당 → 굵게 전체 (해석 묶음에 나오면 성공)
  - 판정판 대상(라인 전체 최악 상태)
  - 타일에 상태 글자 넣기, 현재 투입 정보 위치
  - 최대값 열 단위(혼합 단위)
- 화면 품질은 1126 채점표(10항목, 샘플 합계 정합성 제외)로 참고 채점
