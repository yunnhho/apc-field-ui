# M1 — 포장 팔레트 적재 PalletPacker (Sonnet, 11/27) — 에이전트 보고 요약

**1) 만든 화면과 PNG**

- 데이터 `Data/IMainViewSource.cs`, `Data/SampleMainViewSource.cs`, `Data/PalletRules.cs`(상수·라벨 정규식·중량 판정)
- 앱 exe 실행 안 함.

**2) 점검** — 빌드 0/0, MainForm·PalletCloseDialog 점검 0건.

**3) UX 결정**
- 판정판 맨 위 "3층 · 6번 칸" + 다음 동작. 거부 시 빨강 "박스 거부" + 이유, 경고창 함께. 40개 차면 노랑 "적재 완료".
- 마감 dialog: 박스 수 미달·라벨/사원증 미스캔·중량 미입력·범위 밖이면 [마감] 꺼짐 + 이유 한 줄.
- 층별 요약 5행 고정 표는 세로로 두면 아래가 비어서 가로로 눕힘(층 = 열).

**4) 정한 기준값** — 511.6~532.4 kg 상수(정확한 ±2 %는 511.56·532.44), 라벨 `^BX-(.+)-(\d{5})$`, 스캔 순서 팔레트 라벨 → 사원증 → 중량, 칸에는 팔레트 전체 박스 번호(3층 = 17~24).

**5) 지침에서 막히거나 모호했던 점**
- 적재 도식: Label 조립 허용 규칙대로 Panel 안 Label 8개, Resize에서 위치 계산, `ApcTheme.Status` 색, `ApcStatusLegend`. 칸이 큰데 글자가 테마 폰트 그대로라 작다 — 큰 번호 글꼴 수단 없음.
- `Titled`의 tools 자리에 `ApcStatusLegend`(Dock=Right)를 넣으면 높이 0으로 접혀 점검에 걸림 → 안쪽 Dock=Top으로 옮김. 지침 안내와 다름.
- 고정 5행 표와 남는 Fill 영역 충돌 → 가로로 눕힘.
- 단계형 상태(완료·적재 중·대기)를 램프 열로 못 보여 상태 열 뺌. 진행 중 색 Info vs Warn 모호.
- 판정판과 경고창에 같은 거부 이유가 두 번 — "한 사실은 한 곳"과 어긋날 수 있음.
- 스캔 칸 여럿: 포커스 칸이 다른 종류 코드를 받으면 거부·경고만 하고 맞는 칸으로 옮기지 않음. 지침에 안내 없음.

**확인 질문** — 중량 범위 정확값 / 사원증 등록 검사 / 메인 마감 버튼 미리 끄기 / 마감 후 라벨 인쇄 / 층별 요약 세로 배치 / 칸 번호 층 안 1~8 / 품번 형식.
