## 화면 요청
브레이크 디스크 최종 치수 검사 판정 단말. 프로젝트명 DiscFinalCheck.
목적: 검사기 한 대에서 디스크를 하나씩 스캔하고 측정값으로 OK/NG를 판정한다. 사용자: 검사 작업자 — 검사실 현장 PC, 핸드 스캐너.
메인 화면: 디스크 시리얼 스캔 칸, 마지막 판정(OK/NG와 NG 이유)을 가장 크게, 측정 항목 4개(외경·두께·런아웃·평행도 — 측정값과 기준), 오늘 집계(검사 수·OK·NG·불량률), 오늘 검사 이력 표(시각·시리얼·4항목·판정).
dialog: NG 처리 등록(NG 디스크 정보 읽기 전용, 처리 선택 — 재가공/폐기/재검사, 반장 사원증 스캔). 같은 시리얼이 이미 폐기 등록된 경우 다시 검사하지 못하게 막는다.
