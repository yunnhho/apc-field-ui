## 화면 요청
식품 원료 창고 생산 투입 출고 단말 프로그램. 프로젝트명 RawMaterialIssueTerminal.

메인 화면: 작업지시 바코드 스캔 → 지시 정보(지시 번호·제품·배합 배치 수·투입 라인), 원료별 출고 목록(원료 코드·원료명·필요량·출고량·남은 양·상태), 원료 포대 스캔 판정 결과(OK/NG와 사유) 크게, 선택 원료의 재고 Lot 목록(Lot·입고일·유통기한·잔량·FIFO 순위), [출고 완료] 버튼(모든 원료 필요량 충족 시만), 금일 출고 이력 표.
dialog: FIFO 예외 출고 승인(원료·스캔한 Lot·앞 순위 Lot 읽기 전용, 예외 사유 선택, 승인자 사번 스캔). 유통기한이 지난 Lot은 승인이 있어도 출고할 수 없다.

## 도메인 정보
- FIFO: 같은 원료는 유통기한이 빠른 Lot부터 출고. 앞 순위 Lot이 있는데 뒤 Lot을 스캔하면 NG "FIFO 위반", 예외 승인으로만 출고.
- 유통기한 지난 Lot: NG "유통기한 경과", 출고 불가. 유통기한 7일 이내: 주의(출고는 가능, 노란 표시).
- 알레르기 유발 원료(밀·대두·우유)는 지시서 라인과 원료의 알레르기 라인 구분이 다르면 NG "알레르기 라인 불일치".
- 필요량 허용 오차 ±0.5%. 넘게 스캔하면 "초과" 표시, 출고 완료는 가능.
- 원료 코드 예: RM-1021 소맥분. Lot 예: L261120-03. 작업지시 예: WO-261126-007.
- 표시 형식: 중량 kg 0.0, 날짜 yyyy-MM-dd, 수량 #,0.

결과물

잘한 점

  • 판정판 부제가 할 일을 말합니다: "소맥분 L261120-03 · 앞 순위 L261108-01 먼저 출고".
  • 재고 Lot 표에 FIFO 순위가 있고, 경과와 다른 라인 Lot은 순위에서 뺐습니다. D-6 주의도 표시됩니다.
  • 샘플이 맞습니다. 소맥분 출고 150.0 kg은 이력 6건 × 25 kg과 같고, "미충족 3종"과 "충족 3종"도 목록과 맞습니다.
  • NG 사유마다 예외 승인 버튼 상태가 다릅니다. FIFO 위반일 때만 켜집니다.

감점
