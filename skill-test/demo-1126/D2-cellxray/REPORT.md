3) UX 결정
- 첫 줄에 트레이 최종 판정 판정판을 크게 둔다. 재판정 대기가 있으면 노란색 "재판정 4건 남음", 부제 "칸 14, 18, 26, 39 · 완료 불가". 대기가 없으면 녹색 "트레이 OK", NG 개수는 "NG 박스로" 안내. 옆에 금일 검사·OK·NG·재판정 카드 4개.
- 스캔이 주 동작. 스캔 줄은 판정판 위. 스캔하면 트레이를 불러와 첫 재판정 대기 셀을 자동 선택. 셀 50개(5×10)는 큰 `ApcStatusTile`, 번호만 적고 상태는 램프 색과 범례로.
- [트레이 완료]는 Primary 큰 버튼. 대기가 있으면 `Enabled = false`, 왼쪽에 "대기 4건 · 완료 불가". 핸들러에서도 재검사, 완료 전 Confirm. 진행 중 트레이가 있을 때 다른 트레이 스캔·형식 틀린 바코드는 Warn으로 막음.
- 우측 상단에 선택 셀 측정값 표(오버행 4곳, 정렬 편차, 이물) — 항목마다 램프와 판정 글자, 규격 밖 값은 빨간 굵게. 제목 줄에 셀 ID·칸 번호·자동 판정 사유와 [재판정] 버튼. 아래는 최근 트레이 이력.
- dialog에서 규격 미달 셀(오버행 하한 미만, 정렬 편차 초과)은 판정 콤보에 "OK"가 없고 NG만. 상단 빨간 `ApcNoticeBar` "OK 불가 · 오버행 최소 0.42 mm < 하한 0.50".

4) 정한 기준값(`Data/CellModels.cs`의 `CellSpec`)
- 오버행: 0.50 미만 NG, 0.50~0.60 재판정 대기(양끝 포함), 0.60 초과 OK. 4곳 각각 판정, 셀 판정은 최소값.
- 정렬 편차: 0.30 이하 OK, 초과 자동 NG(요청서에 NG 처리 언급 없음 → 정함). 이물 검출은 재판정 대기.
- 셀 판정: NG 하나라도 → NG, 아니면 대기 하나라도 → 대기, 아니면 OK. OK 변경 차단은 정렬 편차 초과까지 확장.
- 재판정 버튼은 자동 판정 NG·대기 셀에서만. 사유 선택 사항, NG 선택 시 NG 유형 필수.
- 금일 검사 = 완료 트레이 셀 수 + 현재 트레이 50개.
- 샘플 TR-A0153: NG 3칸(07, 32, 45), 대기 4칸(14, 18, 26, 39). 경계값: 오버행 0.50(칸 18), 0.60(칸 39), 정렬 0.30(칸 23, OK).
