## 화면 요청
2차전지 원통형 셀 X-ray 검사 판정 단말 프로그램. 프로젝트명 CellXrayJudgeStation.
목적: 공정 설비 프로그램(X-ray 검사기 한 대 옆 단말). 사용자: 검사 작업자 — 자동 판정 NG 셀을 재판정하고, 트레이 단위로 다음 공정에 넘긴다.
메인 화면: 트레이 바코드 스캔 → 트레이 셀 50개(5×10) 판정 격자(OK/NG/재판정 대기), 선택 셀의 측정값(양극-음극 오버행 최소값 4곳, 젤리롤 정렬 편차, 이물 유무), 트레이 최종 판정 큰 표시, [트레이 완료] 버튼(재판정 대기 셀이 하나라도 있으면 막는다), 금일 검사·OK·NG·재판정 수, 최근 트레이 이력 표.
dialog: NG 셀 재판정(셀 ID·자동 판정 사유·측정값 읽기 전용, 판정 OK/NG 선택, NG 유형 선택, 사유). 오버행 측정값이 규격 하한 미만인 셀은 OK로 바꿀 수 없다.

## 도메인 정보
- 셀 규격 21700. 오버행(음극이 양극보다 튀어나온 길이) 규격: 0.50 mm 이상, 0.50~0.60 mm는 경계(자동 판정 "재판정 대기"), 0.50 미만은 NG 확정.
- 젤리롤 정렬 편차 0.30 mm 이하 OK. 이물 검출 시 재판정 대기(사람이 이미지로 확인).
- NG 유형: 오버행 부족, 정렬 불량, 이물, 탭 접힘, 기타.
- 트레이 단위로 다음 공정(전해액 주입)에 넘긴다. NG 셀은 트레이에서 빼서 NG 박스로 보내고 트레이에는 빈칸으로 남긴다.
- 셀 ID 예: C2611260001. 트레이 ID 예: TR-A0153.
- 표시 형식: 길이 mm 0.00, 수량 #,0, 시각 HH:mm:ss.
