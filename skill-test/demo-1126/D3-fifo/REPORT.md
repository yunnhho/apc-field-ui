3) UX 결정
- 맨 위 큰 판정판 "NG · FIFO 위반", 아래 줄에 원료·Lot·앞 순위 Lot. 옆에 "충족 원료 3종 / 전체 6종" 카드.
- 스캔 입력란 하나: `WO-`면 작업지시, `원료코드/Lot/중량`이면 포대 라벨, 그 밖은 경고. 아래 한 줄에 지시 정보(지시, 제품, 배치 수, 투입 라인, 알레르기 라인).
- NG면 출고 기록 안 함 + 사유 글. 유통기한 경과·알레르기 불일치·지시서에 없는 원료·미등록 Lot은 [FIFO 예외 승인] 꺼짐 + 이유. FIFO 위반만 켜짐.
- 예외 승인 dialog: 원료·스캔 Lot·앞 순위 Lot 읽기 전용, 사유 선택 + 승인자 사번 스캔. 사유·사번 없으면 [승인] 꺼짐 + 이유. 유통기한 경과 Lot이 넘어와도 "유통기한 경과 · 승인 불가"로 꺼진 채.
- [출고 완료]는 원료별 출고 목록 제목줄, 미충족 있으면 꺼짐 + "필요량 미충족 3종".
- 재고 Lot 표는 선택 원료만, 순위는 FIFO 대상에만, 마지막 스캔 Lot 굵게, 상태 정상/주의/경과/라인 다름.

4) 정한 기준값
- 허용 오차 ±0.5%: 99.5% 이상 충족, 100.5% 초과면 초과.
- 유통기한 D-7 이하 주의, 오늘보다 이전이면 경과(오늘까지 사용 가능).
- 판정 순서: 지시서에 없는 원료 → 미등록 Lot → 유통기한 경과 → 알레르기 불일치 → FIFO 위반 → OK.
- FIFO 순위: 유통기한, 입고일, Lot 순. 경과·소진·다른 라인 Lot 제외.
- 알레르기 라인 구분은 Lot에 붙임(요구 없음 → 정함).
- 승인 사유 4종(임의): 포장 훼손, 잔량 부족, 품질팀 출고 지시, 분석 대기. 승인자 사번 EMP-2041, EMP-2077.
- 라벨 형식 `RM-1021/L261120-03/25.0`. 오늘 2026-11-26 고정.
