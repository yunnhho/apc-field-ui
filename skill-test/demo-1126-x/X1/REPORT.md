## 3) UX 결정
- 판정판은 탭과 무관하게 전 설비 중 가장 나쁜 것. 원인은 표 "내용" 열에 붉은 굵은 글씨.
- [작업 시작]은 가동 중·통신 끊김 설비에서 꺼지고 왼쪽에 "가동 중 · 전송 불가".
- dialog: 레시피 없음, 바렐번호 누락, 조건이 다른 Lot 혼합 → 경고창·미전송. 통과하면 설비 상태 "전송됨". 가동 클릭 자동 시작은 화면 밖이라 구현 안 함.
- 설비 표는 고정 8행, 아래 빈 공간은 ZWORK3033_A 전송 이력(작업 조건 / 시작 5분 후 / 완료, 재전송 대기 포함).
- 판정 함수는 `UnitJudge.Evaluate` 하나.

## 4) 정한 기준값
RPM ±10 rpm(경고 단계 없음) · 시작 후·종료 전 3.0분(경계 포함) RPM 판정 제외 · 완료 시 PV/SV 시간 허용 1.0분 · 저속 RPM SV 370(요구), 고속 450(임의) · 시간 분 단위(SV 정수, PV 0.0) · 설비 14대(고속 8, 저속 6).

## 5) 요구사항에서 읽은 것 / 반영하지 않은 것
- 읽음: 시간 SV/PV·RPM PV 주소, 저속 2·고속 4 스캔 + 바렐번호 수기, 같은 조건만 전송, 레시피 없으면 미전송, RFC 조회 항목, ZWORK3033_A(5분 후·완료, 실패 1분 후 재전송), 알람 방향(3분 제외, SV 대비 시간 차이).
- 안 함: **담당자 비밀번호 강제 입력**(템플릿 복사 부담으로 생략), 56대 구성(모호 → 14대), 자재코드 자리 추출·용량 환산·BBO 칩 구분·기준정보 마스터 매칭, 실제 RFC·PLC, 사번·작업자, PMS 조회 화면, 가동 자동 시작.

## 6) 지침 모호점
- 한국어 .cs heredoc 금지가 Python heredoc에도 해당하는지 없음(실제로 치환 실패).
- "표 아래 빔" 참고 vs "정해진 목록은 그대로" 충돌 → 보조 이력 표로 채움.
- 탭마다 행 수가 다를 때 고정 높이 기준 없음 → 최대 행 기준.
- 최악 수준 2건일 때 SubText 형식 없음 → "A · B".
- dialog 전송 직후 메인 상태를 어디까지 바꿀지 기준 없음 → "전송됨".
