## 3) UX 결정
- 판정판은 탭과 무관하게 56칸 중 가장 나쁜 상태. 다음에 가동·대기·통신 끊김 카드.
- 가동 중·통신 끊김 설비는 전송 아이콘 회색, 누르면 Warn.
- dialog: 레시피 없음·조건 불일치·바렐번호 누락이면 [전송] 꺼짐, 이유는 하단 글.
- 레시피 없음·조건 불일치일 때만 [조건 강제 입력] → 담당자 비밀번호 → 조건 입력.
- 알람 원인은 판정판 SubText("저속연마 1호기 -3 · 352 rpm (기준 370 ± 10)")와 상태 열("가동 · RPM 이탈"), RPM 값 빨강 굵게.

## 4) 정한 기준값
저속 RPM 370(요구) ±10(가정, 경계 정상, 경고 단계 없음) · 시작 후 3분·종료 3분 전 RPM 알람 없음(345 rpm 비알람 샘플) · 목표 시간 그린칩 1시간·소성칩 2시간(PMS 시트) · 표시 hh:mm:ss · 설비 56칸 = 14호기 × 4칸(-1~-4), 저속 LOT 최대 2·고속 최대 4 · 상태: 가동 Run, 전송됨 Info, 대기·끊김 Stop, RPM 이탈 Alarm.

## 5) 읽은 것 / 반영하지 않은 것
- 읽음: 설비 선택 → 스캔 + 바렐번호 수기, 저속 2/고속 4, 조건 다르면·레시피 없으면 경고·미전송, 담당자 비밀번호 강제 입력, 가동 중 전송 불가, 컨트롤러 주소, ZWORK3033_A, 알람 방향, 칩 구분별 시간.
- 안 함: SAP 조회 로직(BBO 칩 구분, 자재코드 파싱, 용량 환산, 바렐수 마스터 — `FindCondition` 자리만), 리턴 RFC 5분 후·완료·1분 재전송, 시간합 vs SV 알람, PMS 조회 화면·"연마 추가" 요청, 가동 자동 시작, 사번·작업자.

## 6) 지침 모호점
- JudgeView vs FailureAnalysisView 선택 기준 없음 → FailureAnalysisView. 56대를 탭/타일 중 어떻게 보일지 없음.
- 대기 카드 색(Stop?) 기준 없음.
- 스캔 dialog를 LotInputDialog(표 셀 입력) vs `ApcScanBox` 중 무엇으로 할지 불분명 → 표 셀.
- 도구: CellEndEdit에서 모달 Warn을 BeginInvoke로 띄우면 render가 간헐적으로 멈춤(셀만 지나가도 이벤트). "스캔 중 경고는 BeginInvoke" 지침이 셀 편집 경로에서는 함정.

### 확인 질문
**정한 기준값** 1. 저속 370 ±10, 고속 RPM은 SV 없어 값만 2. 종료 3분 전 = 목표 시간 기준 3. hh:mm:ss, 그린 1h·소성 2h
**해석** 4. 자재코드·구분·목표 시간 모두 같을 때만 전송 5. 강제 입력은 레시피 없음·조건 불일치만
**배치** 6. 56칸 = 탭 4개 + 표 (타일 격자?)
**데이터 모양** 7. LOT·자재코드·바렐번호(2자리)·비밀번호 확인 방식은 샘플
