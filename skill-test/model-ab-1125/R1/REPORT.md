**3) UX 결정**

- 사유 비면 `Warn`으로 막음. Scrap은 빨간 확인창.
- 이력 표 기준 미달 행: 빨간 램프 + 굵은 빨간 글자 + "기준 미달 · Hold".

**4) 정한 기준값**

- 메인 창 1920x1080(기본 1600x900에서는 이력 표 행이 거의 안 들어감).
