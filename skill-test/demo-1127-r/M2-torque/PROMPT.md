## 화면 요청
실린더 헤드 커버 체결 순서 프로그램. 프로젝트명 TorqueSequence.
목적: 볼트 10개를 정해진 순서로 체결하고 포인트별 토크를 판정한다. 사용자: 조립 작업자 — 조립 라인 체결 공정 현장 PC.
메인 화면: 부품 윤곽 도식 위 체결 포인트 10개(번호 표시, 다음 체결할 포인트 강조, 끝난 포인트는 OK/NG 색), 현재 포인트의 토크값을 크게, 부품 시리얼 스캔 칸 + 작업자 사원증 스캔 칸(둘 다 스캔해야 시작), 포인트별 결과 표(번호·토크·각도·판정), 모드 전환: 자동(체결 공구 통신값) / 수동(토크렌치 측정값을 직접 입력 — 수동일 때만 입력 칸이 나온다).
dialog: 재체결 승인(NG 포인트 정보 읽기 전용, 반장 사원증 스캔, 사유 선택). 같은 포인트 NG 2회째면 재체결을 막고 부품 불량 처리로 안내한다.

## 도메인 정보
- 토크 기준 9.0~11.0 N·m(경계 포함 OK), 각도 30~60°(경계 포함 OK). 둘 다 OK여야 포인트 OK.
- 체결 순서 고정: 1-6-2-7-3-8-4-9-5-10(지그재그). 순서가 아닌 포인트 체결값이 오면 막는다.
- 부품 시리얼 HC-yyMMdd-nnnn, 사원증 EMP-nnnnn, 반장 사원증은 EMP-9로 시작.
- 표시 형식: 토크 0.0 N·m, 각도 정수 °, 시각 HH:mm:ss.
