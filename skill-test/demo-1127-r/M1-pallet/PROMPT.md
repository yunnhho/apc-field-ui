## 화면 요청
포장 라인 팔레트 적재 프로그램. 프로젝트명 PalletPacker.
목적: 박스를 정해진 적재 패턴대로 팔레트에 쌓고, 다 쌓으면 팔레트를 마감한다. 사용자: 포장 작업자 — 포장 라인 끝 현장 PC.
메인 화면: 팔레트를 위에서 본 적재 도식(층마다 2×4 = 8칸, 5층. 현재 층 칸에 박스 순번 표시, 칸 색 = 빈칸/적재/다음 놓을 칸), 팔레트 제목에 진행 현황(예 "3층 · 21/40 박스"), 박스 라벨 스캔 칸, 층별 요약 표(1~5층: 박스 수·완료 시각), 현재 작업 지시(품번·고객사·목표 박스 수).
dialog: 팔레트 마감(팔레트 라벨 스캔 + 작업자 사원증 스캔, 총중량 측정값 입력). 박스 수가 목표보다 적거나 총중량이 허용 범위를 벗어나면 마감을 막는다.
