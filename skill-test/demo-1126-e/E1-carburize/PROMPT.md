## 화면 요청
기어 부품 침탄 열처리로 배치 모니터링 프로그램. 프로젝트명 CarburizeFurnaceMonitor.
목적: 모니터링 + 배치 종료 판정(열처리로 4기). 사용자: 열처리 작업자·열처리 기술자 — 열처리동 현장 PC.
메인 화면: 로 4기(CF-1~CF-4) 상태 타일(가열/침탄/확산/냉각/대기/알람), 선택 로의 현재 배치 정보(배치 번호·품번·적재 수량·레시피), 공정 단계 진행(단계별 설정 시간 대비 경과), 현재값 카드(로 온도·카본 포텐셜·유조 온도), 선택 로의 이번 배치 온도·CP 프로파일(설정값 겹쳐 표시), 최근 배치 이력 표(배치·품번·시작·종료·판정·경도 시편 결과).
dialog: 배치 종료 판정(배치 정보 읽기 전용, 시편 표면경도·유효경화깊이 입력, 판정 자동 표시). 공정 중 알람이 한 번이라도 있었으면 기술자 사원증 스캔 없이는 "합격"으로 종료할 수 없다.

## 도메인 정보
- 레시피 GR-20: 가열 880℃ 60분 → 침탄 930℃ CP 1.10% 180분 → 확산 930℃ CP 0.80% 60분 → 강온 850℃ 30분 → 유냉(유조 60~80℃) 20분.
- 온도 허용 ±10℃, CP 허용 ±0.05%. 벗어나 1분 넘으면 알람.
- 시편 판정: 표면경도 HRC 58~62, 유효경화깊이 0.8~1.2 mm. 하나라도 벗어나면 불합격.
- 1배치 = 트레이 4단, 트레이당 기어 120개.
- 표시 형식: 온도 ℃ 정수, CP % 0.00, 경도 HRC 0.0, 깊이 mm 0.00, 시간 HH:mm.
