**3) UX 결정**
- 맨 위 왼쪽 판정판이 라인 전체에서 가장 급한 것 하나: "CF-3 알람 / 침탄 CP 하한 미달 1.00 % (하한 1.05) · 4분째". 알람이 없으면 종료 판정 대기 로. 오른쪽 로 타일 4칸, 누르면 아래 전체가 그 로로 바뀜. 처음 선택은 CF-3.
- [배치 종료 판정]은 선택 로가 전 단계 완료일 때만 켜짐. 막히면 "공정 진행 중 · 종료 판정 불가".
- dialog: 시편 값 입력 전 "입력 대기", 알람 이력 배치는 합격 범위여도 "확인 필요"로 막고 기술자 사원증 스캔(`Scanned` 이벤트만 인정)으로 풀림. 불합격은 스캔 없이 종료 가능. 종료 확인 창은 취소가 기본.
- 이력표는 불합격 행의 범위 밖 수치만 빨간 굵은 글씨.

**4) 정한 기준값**
- 온도 ±10 ℃, CP ±0.05 %, 1분 초과 알람, 경도 58.0~62.0 HRC, 깊이 0.80~1.20 mm, 1배치 480개.
- 한계값과 같으면 정상/합격. 샘플: 로 온도 920 ℃(하한), 이력 62.0 HRC / 1.20 mm / 58.0 HRC / 0.80 mm.
- 벗어난 지 1분 이하 Warn, 초과 Alarm. 유조 60~80 ℃는 유냉 단계에서만, 벗어나면 즉시 Alarm. 강온 CP = 확산 0.80 % 가정.
- 종료 판정 대기 로는 타일 Warn("냉각 완료"). 샘플 현재 15:15: CF-1 확산 / CF-2 대기 / CF-3 침탄 알람 / CF-4 냉각 완료. 이력 15행.
- 이력 시작·종료는 HH:mm만, 날짜는 배치 번호(`CF3-1125-04`)로 구분. 프로파일은 5분 간격, 점선은 현재 단계 설정 ± 허용.
- 배치 번호 `CFn-MMdd-nn`, 품번 `GR-4521A`/`GR-3307C`, 사원증 `TECH-` 접두.

**5) 지침 모호점**
- `ApcTrendChart` `Reference`가 상수 한 줄뿐이라 단계별 설정 곡선을 못 그림 → 현재 단계 설정 ± 허용으로 대신. 스킬에 한계 안내 없음.
- 온도 차트가 25 ℃부터라 세로축 0~1000, ±10 띠가 한 줄로 붙음. 축 범위 속성 없음.
- 시간 형식 요구(HH:mm) vs 스킬(여러 날 이력은 날짜 포함) 충돌 → 요구 우선.
- 판정판 대상(라인 전체/선택 로) 지침 없음 → 전체.
- 판정판이 알람 하나만 말해 동시에 판정 대기인 CF-4는 노란 타일로만 보임.
- 스캔 Enter 삼킴·타자 구분이 api.md에 짧음 → `Scanned` 이벤트만 인정.
