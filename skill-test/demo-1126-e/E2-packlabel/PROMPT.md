## 화면 요청
완성차 납품용 전장 부품 출하 포장 검수 단말. 프로젝트명 ShipPackVerifier.
목적: 작업(포장 라인 1곳, 작업자 1명). 사용자: 포장 작업자 — 포장대 옆 터치 없는 PC, 핸드 스캐너.
메인 화면: 현재 출하 지시(지시 번호·고객사·납품처·품번·지시 수량·박스 입수), 진행 상황(완료 박스/전체 박스, 현재 박스 담은 수량/입수), 마지막 스캔 결과를 가장 크게(OK/NG와 이유), 현재 박스에 담은 제품 시리얼 목록, 완료 박스 목록(박스 번호·수량·라벨 출력 시각). 박스가 차면 라벨 출력 버튼.
dialog: 박스 라벨 재출력(박스 선택, 사유 선택 — 라벨 훼손/오출력/고객 요청, 반장 사원증 스캔). 반장 스캔 없이는 재출력할 수 없다.
막을 것: 다른 품번 시리얼, 이미 담은 시리얼(중복), 품질 보류 시리얼, 박스 입수 초과. 박스가 덜 찼으면 라벨 출력 불가(마지막 박스만 예외).
