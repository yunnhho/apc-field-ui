메인 화면: 로 4기(CF-1~CF-4) 상태 타일(가열/침탄/확산/냉각/대기/알람), 선택 로의 현재 배치 정보(배치 번호·품번·적재 수량·레시피), 공정 단계 진행(단계별 설정 시간 대비 경과), 현재값 카드(로 온도·카본 포텐셜·유조 온도), 선택 로의 이번 배치 온도·CP 프로파일(설정값 겹쳐 표시), 최근 배치 이력 표(배치·품번·시작·종료·판정·경도 시편 결과).

## 도메인 정보
- 레시피 GR-20: 가열 880℃ 60분 → 침탄 930℃ CP 1.10% 180분 → 확산 930℃ CP 0.80% 60분 → 강온 850℃ 30분 → 유냉(유조 60~80℃) 20분.
- 온도 허용 ±10℃, CP 허용 ±0.05%. 벗어나 1분 넘으면 알람.
- 시편 판정: 표면경도 HRC 58~62, 유효경화깊이 0.8~1.2 mm. 하나라도 벗어나면 불합격.
- 1배치 = 트레이 4단, 트레이당 기어 120개.
- 표시 형식: 온도 ℃ 정수, CP % 0.00, 경도 HRC 0.0, 깊이 mm 0.00, 시간 HH:mm.

- 금형 번호 형식: DM-품번앞4자리-두자리(예: DM-HS21-03). 한계 타수 금형마다 80,000~120,000.
- 남은 비율 10% 이하 주의, 3% 이하 교체 필요. 한계 도달 금형은 생산 불가.
- 교체 표준 시간 45분, 60분 넘으면 지연 표시.
- 예열 온도 기준 180~220℃(작업자가 온도계로 보고 체크만 한다).
- 표시 형식: 타수 천 단위 쉼표 정수, 비율 % 0.0, 시각 HH:mm, 소요 분 정수.

결과물

잘한 점

  • 판정판 부제가 어느 설비의 어느 금형인지 바로 말합니다: "DC-05 DM-KB07-11 한계 도달 · DC-02 DM-HS21-03 남은 3.0 %".
  • 경계값 샘플이 촘촘합니다. 비율 10.0%(주의)·3.0%(교체 필요)·0.0%(한계 도달), 소요 60분(지연 아님)·62·72분(지연).
  • 장착 금형과 다음 지시 금형을 같은 항목으로 나란히 놓은 비교 표가 교체 판단에 바로 쓰입니다.
  • 막는 조건 4개가 MoldRules.BlockReason 한 함수에 있고, 메인 버튼과 dialog가 같은 함수를 씁니다(코드 확인).
  • 체크박스가 없는 라이브러리에서 "예열 확인"을 문장이 든 큰 토글 버튼으로 만들었습니다.

감점

  • 5 △ "교체 필요"가 두 뜻으로 쓰입니다. 수명 표에서는 남은 3% 이하, 비교 표 제목줄에서는 "교체 필요 · 지시 금형과 다름". 같은 화면에서 같은 말이 다른 조건을 가리킵니다.

확인 질문 8개(기준값 2 · 해석 3 · 배치 2 · 데이터 1). 5번 "이미 다른 설비에 장착된 금형도 막을까요?"는 요청에 없던 막기 규칙을 스스로 찾아낸 좋은 질문입니다.
