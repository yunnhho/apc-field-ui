**3) UX 결정**

- 수명 경고 표는 남은 비율 낮은 순, 판정 열 글자. 10.0%·3.0% 경계 행, 계획·실적에 60분(지연 아님)·62·72분(지연).
- 선택 설비가 교체 중이면 [금형 교체 등록] 꺼짐 + 이유. dialog [등록]은 수리 대기·남은 타수 0 이하·지시 금형 불일치·교체 중이면 꺼지고 빨간 이유. 판정은 `MoldRules.BlockReason`.
- dialog는 금형 스캔, 사원증 스캔, 예열 확인 버튼으로 끝. 제거·지시 금형은 자동 읽기 전용.

**4) 정한 기준값**
- 남은 비율 = 남은 타수 ÷ 한계 타수. 10% 이하 주의, 3% 이하 교체 필요(경계 포함), 0 이하 한계 도달.
- 교체 소요 60분 초과부터 지연(60분은 아님). 표준 45분은 상수만. 진행 중은 샘플 현재 15:20 기준.
- 설비 상태: 교체 중 > 정지 > 교체 예정(장착 금형 10% 이하) > 생산. 색: 생산 Run, 교체 예정 Warn(3% 이하 Alarm), 교체 중 Info, 정지 Stop, 한계 도달 정지 Alarm.
- 금형 번호 `^DM-[A-Z0-9]{4}-\d{2}$`, 사원증 6자리 숫자, 지시 WO-2611-0xx, 예열 180~220℃ 상수, 저장 위치 "보관실".

**5) 지침 모호점**
- 체크박스 컨트롤이 없어 "예열 확인 체크"를 토글 `ApcButton`으로 만듦.

- 타일 "이름만" vs 상태 글자 요구 → `Text`에 "DC-01  교체 예정".
- `Titled` tools에 `Caption`을 넣으면 제목줄 높이가 달라져 옆 표가 6행만 보이고 스크롤바 → `TitledHeight(..., true)`로 해결. 높이 맞추려 넣은 `ApcStatusLegend`는 크기를 안 주면 높이 0으로 접힘.
- `ApcInfoStrip` 폭이 좁으면 말줄임 → dialog 폭 920. 폭 기준 없음.

### 확인 질문
**정한 기준값**
1. 남은 비율을 "남은 타수 ÷ 한계 타수"로 보고 10% 이하 주의, 3% 이하 교체 필요(경계 포함)로 했습니다. 다른 기준(예: 신품 대비)으로 할까요?
2. 교체 소요 60분 초과부터 지연, 정확히 60분은 지연 아님으로 했습니다. 60분 이상을 지연으로 할까요?
**해석**
3. 판정판이 장착 금형이 교체 필요인 설비 전체를 말하게 했습니다. 선택 설비 기준으로 바꿀까요?
4. 교체 중=파랑, 교체 예정=노랑(3% 이하 빨강), 한계 도달 정지=빨강으로 했습니다. 교체 중을 초록(Run)으로 할까요?
5. 수리 대기·남은 타수 0 이하·지시 금형 불일치 외에 "이미 다른 설비에 장착된 금형"도 막을까요? 지금은 막지 않았습니다.
**배치**
6. 수명 경고 표는 10% 이하만 7행 고정, 보관실 금형 포함입니다. 장착 설비 금형만 보이게 할까요?
7. 비교 표를 중간 줄 오른쪽에, 불일치 안내는 제목줄 오른쪽 글로 두었습니다. 별도 알림 띠로 올릴까요?
**데이터 모양**
8. 금형 번호·사원증 6자리·지시 번호 형식은 제가 정한 값입니다. 사원증 이름 조회가 필요한지, 실제 형식은 무엇인지 알려 주세요.
