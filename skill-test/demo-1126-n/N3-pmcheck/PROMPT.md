## 화면 요청
프레스 설비 예방보전(PM) 점검 진행 프로그램. 프로젝트명 PressPmChecklist.
목적: 정해진 순서대로 점검 항목을 하나씩 진행하고 결과를 남긴다. 사용자: 보전 작업자 — 프레스 라인 옆 현장 PC.
메인 화면: 점검 대상 설비 사원증·설비 바코드 스캔으로 시작. 점검 단계 진행 표시(전체 단계 중 현재 위치, 완료/NG/남음), 현재 단계 하나를 크게(항목명, 점검 방법 설명, 기준, 입력: OK/NG 버튼 또는 측정값), 이전 단계 결과 목록, 진행 시간. 현재 단계를 끝내기 전에는 다음 단계로 갈 수 없다. 안전 단계(전원 차단·잠금 확인)는 완료 전 모든 다른 단계를 막는다.
dialog: 점검 완료(설비·점검자·소요 시간·단계별 결과 요약 읽기 전용, NG 항목 목록). NG 항목이 있으면 정비 요청 등록 없이는 "점검 완료"로 닫을 수 없다.

## 도메인 정보
- 점검 항목(순서대로): 1 전원 차단·LOTO 잠금 확인(안전) / 2 유압 작동유 레벨 육안 OK/NG / 3 유압 압력 측정 18.0~21.0 MPa / 4 클러치·브레이크 정지 시간 측정 ≤ 180 ms / 5 슬라이드 평행도 측정 ≤ 0.05 mm / 6 윤활유 공급 육안 OK/NG / 7 안전 광커튼 차광 시험 OK/NG / 8 비상정지 버튼 작동 OK/NG.
- 측정값이 기준 밖이면 NG. NG여도 다음 단계로 진행 가능(안전 단계 제외).
- 설비 바코드 EQ-PRS-nn, 사원증 EMP-nnnnn.
- 표시 형식: 시각 HH:mm, 소요 시간 mm:ss, 압력 MPa 0.0, 시간 ms 정수, 평행도 mm 0.00.
