## 화면 요청
사출 성형기 교대 생산 계획 간트 보드. 프로젝트명 MoldingShiftGantt.
목적: 교대 중 계획 대비 진행 확인 + 긴급 작업 끼워넣기. 사용자: 사출 반장·생산관리 — 사출동 현장 PC.
메인 화면: 성형기 8대(IM-01~IM-08) × 주간 교대(08:00~20:00) 시간축 간트. 설비 한 줄마다 계획 작업 막대(품번·수량), 그 아래 실적 막대, 금형 교체 구간과 비가동(고장) 구간을 다른 표시로, 현재 시각 세로선. 위쪽에 교대 계획 달성률과 지연 설비 수. 막대를 누르면 작업 상세(품번·금형·계획/실적 수량·사이클타임·예상 종료).
dialog: 긴급 작업 끼워넣기(작업 지시 바코드 스캔, 대상 성형기 선택, 끼워 넣을 위치 선택, 뒤 작업이 밀리는 결과 미리보기). 금형이 대상 성형기 톤수에 맞지 않으면 막고, 밀린 작업 중 납기가 오늘인 것이 생기면 생산관리 사원증 스캔 없이는 확정할 수 없다.

## 도메인 정보
- 성형기 톤수: IM-01~04 180 t, IM-05~08 350 t. 금형마다 필요 톤수가 있다(예 M-2201 150 t, M-3510 320 t).
- 금형 교체 표준 40분. 작업 사이에 품번이 바뀌면 자동 삽입.
- 지연 = 현재 시각 기준 실적이 계획보다 10% 이상 적음.
- 작업 지시 바코드 WO-yyMMdd-nnn.
- 표시 형식: 시각 HH:mm, 수량 정수(천 단위 쉼표), 사이클타임 초 0.0, 달성률 % 0.0.
