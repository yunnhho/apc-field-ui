- `참고:` 줄은 랙 표 4개의 "표 아래가 빔". 랙은 5단 고정 표라서 그대로 뒀다.

**3) UX 결정**
- 맨 위 왼쪽 큰 판정판: 입고 추천 위치("입고 → B-1-01") 또는 출고 위치. 같은 위치가 아래 맵에서 초록으로 강조. 오른쪽이 스캔칸과 [위치 확정].
- 스캔은 스캐너만. 팔레트(PL-) 스캔 시 등록 여부와 랙 안 위치로 입고·출고 자동 판정.
- 막는 동작과 이유:
  - 보류 팔레트: "출고 불가 · 품질 보류", 확정 버튼 꺼짐.
  - 빈 칸 없음: "입고 불가".
  - FIFO 위반: 판정판이 "더 오래된 B-1-04 먼저"를 알리고, dialog에서 사원증 스캔 전까지 확정 꺼짐. 이유는 확정 버튼 왼쪽 빨간 글.
  - 추천과 다른 칸 라벨 스캔: 경고창 후 거부.
  - FIFO 예외 허용은 데이터 쪽 사원증 권한 판정(`IsAuthorizedBadge`)으로만.
- 랙 A~D는 2×2, 각 랙 제목에 적재율과 칸 수. 창 높이에 맞춰 칸 높이가 늘어남. 오른쪽은 오늘 입출고 이력.
- 칸 색은 범례: 회색 빈칸, 파랑 적재, 빨강 보류, 노랑 장기재고, 초록 추천·출고 위치.

**4) 정한 기준값**
- 입고 추천: 무거운 품번(600 kg 초과)은 1~2단만. 가벼운 품번은 3~5단 먼저, 다 차면 1~2단. 같은 단 안에서는 랙 A→D, 열 1→12 순서의 첫 빈 칸.
- 위치 코드 `B-3-07`, 라벨 `LOC-B-3-07`. 팔레트 바코드 `PL-yyMMdd-nnnn`, 날짜 부분을 입고일로 씀.
- 장기재고는 입고 후 30일 초과(`>30`). 보류 팔레트는 출고 불가, FIFO 비교에서도 제외.
- FIFO는 같은 품번에서 입고일이 더 빠른 출고 가능 팔레트가 있으면 걸림. 입고일이 같으면 걸지 않음.
- 이미 랙에 있는 팔레트 스캔 = 출고, 없으면 입고.
- 담당 사원증 `EMP-0007`, `EMP-0012`(샘플). 작업자는 `CurrentWorker`(샘플). 사원증 예외 사용 내역은 이력에 안 남김.
- 품번 약어 3글자(HX3, BR2, PM4 등). 오늘 2026-11-26 고정.
- 시작 시 시연용으로 PM-450 720 kg 입고 대기 팔레트를 스캔한 상태. 실제 시작 상태는 `MainView(source, null)`이 READY.
- 기본 창 1600×900, render 1920×1080.

**5) 스킬 지침에서 막히거나 모호했던 점**
- **랙 맵 칸 컨트롤이 없다.** 5×12 칸 색 맵을 그릴 컨트롤이 없고 `ApcStatusTile` 240개는 너무 좁고 무겁다. 그래서 `ApcGrid`를 랙마다 하나 두고(첫 열 단, 머리줄 열 번호), 칸마다 `Style.BackColor`를 상태색 `ApcTheme.Status`를 흰색에 섞어 연하게 칠했다. 글자는 품번 약어. 선택색은 같은 값으로 맞춰 눌러도 안 변함.
  - 지침의 "행 배경을 상태색으로 칠하지 말라"와 부딪힌다. 상태가 색만으로 읽혀 범례(`ApcStatusLegend`)로만 보완.
- 랙 제목 적재율 갱신을 위해 `Titled`가 만든 `Label`을 재귀로 찾아 `Text`를 바꿨다. `Titled`에 제목 갱신 수단이 없다.
- 랙 칸 높이가 창 크기에 맞게 늘도록 `Resize`에서 `Columns` 줄 높이와 행 높이를 직접 계산했다. "높이를 추측하지 말라"와 달라 보이지만 표를 Fill로 늘릴 방법이 없었다.
- 스캔칸을 `Titled` 내용으로 넣으면 높이 전체로 늘어나서 `Panel`(스캔칸 Dock Top + 안내 Caption)로 감쌌다.
- dialog 스캔칸 두 개(위치 라벨·사원증): 스캔 값은 포커스 칸으로만 들어와서 접두사(`EMP-`/`LOC-`)로 맞는 칸으로 옮겼다. 지침은 포커스 칸으로 간다고만 말한다.

### 확인 질문
**정한 기준값**
1. FIFO 판정에서 입고일이 같으면 걸지 않게 했습니다. 같은 날이면 팔레트 번호 순으로 FIFO를 걸까요?
2. 가벼운 품번은 3~5단을 먼저 쓰고 1~2단을 무거운 품번 몫으로 남겼습니다. 가벼운 품번도 1단부터 채울까요?
**해석**
3. 보류 팔레트는 FIFO 비교에서 제외했습니다. 보류도 더 오래된 팔레트로 보고 출고를 막을까요?
4. 이미 랙에 있는 팔레트 스캔은 자동으로 출고로 봤습니다. 입고·출고를 작업자가 먼저 고르게 할까요?
5. 사원증 예외 사용은 이력에 남기지 않았습니다. 허용자를 남길까요?
**배치**
6. 랙 칸 색을 `ApcGrid` 칸 배경으로 직접 칠하고 범례로 읽게 했습니다. 칸 안 기호(예: 보류 "!")로 더 보완할까요?
7. 랙을 A~D 4줄 세로가 아니라 2×2로 놓았습니다. 4줄 세로로 바꿀까요(칸이 작아짐)?
**데이터 모양**
8. 품번 약어 3글자, 담당 사원증 `EMP-nnnn`, 위치 라벨 `LOC-`, 작업자 이름은 임의로 만들었습니다. 실제 형식을 알려 주실 수 있을까요?
