## 화면 요청
완제품 창고 랙 위치 관리 프로그램. 프로젝트명 FgRackLocator.
목적: 팔레트 입고 위치 지정 + 출고 위치 안내(선입선출). 사용자: 창고 지게차 기사·창고 담당 — 창고 입구 현장 PC.
메인 화면: 랙 A~D 4줄 위치 맵(랙마다 5단 × 12열 칸, 칸 색 = 빈칸/적재/보류/장기재고, 칸에 품번 약어 표시), 팔레트 바코드 스캔 칸, 스캔하면 입고 추천 위치 또는 출고 대상 위치를 맵에서 강조, 랙별 적재율, 오늘 입출고 이력 표(시각·구분·팔레트·품번·위치·작업자).
dialog: 위치 확정(스캔한 팔레트 정보 읽기 전용, 추천 위치, 위치 라벨 스캔으로 확정). 추천 위치와 다른 칸 라벨을 스캔하면 막고, 출고는 같은 품번의 더 오래된 팔레트가 있으면 막는다(담당 사원증 스캔 시 예외 허용).

## 도메인 정보
- 위치 코드: 랙-단-열, 예 B-3-07. 1칸 = 팔레트 1개.
- 무거운 품번(팔레트 600 kg 초과)은 1~2단에만 입고.
- 장기재고 = 입고 30일 초과. 보류 = 품질 보류 팔레트(출고 불가).
- 팔레트 바코드 PL-yyMMdd-nnnn, 위치 라벨 LOC-B-3-07.
- 표시 형식: 시각 HH:mm, 날짜 MM-dd, 중량 kg 정수, 적재율 % 정수.
