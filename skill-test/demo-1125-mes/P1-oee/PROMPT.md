## 화면 요청
프레스 라인 설비 가동 현황 프로그램. 프로젝트명 PressLineOee.
목적: 모니터링(라인 전체). 사용자: 라인 반장 — 현장 사무실 PC에 상시 띄워 두고, 설비가 멈추면 정지 사유를 입력한다.
메인 화면: 프레스 6대(P01~P06) 상태 타일(가동/비가동/계획정지), 선택 설비의 가용률·성능효율·양품률·OEE 카드, 금일 생산·양품 수량, 비가동 이력 표(설비·시작·종료·시간·대분류·세부 사유·입력자). 사유가 비어 있는 5분 이상 정지는 표에서 눈에 띄게 하고, 행을 골라 사유를 입력한다.
dialog: 비가동 사유 입력(설비·시작·종료 읽기 전용, 대분류·세부 사유 선택, 비고).

## 도메인 정보 (MES 학습 경로 W02·W05)
- 생산일자: 하루 시작 06:00. 주간 06:00~14:00 / 오후 14:00~22:00 / 야간 22:00~06:00. 화면의 "금일"은 생산일자 기준.
- OEE = 가용률 × 성능효율 × 양품률. 가용률 = 가동시간 / 부하시간(계획정지 제외), 성능효율 = 이론 CT × 생산수 / 가동시간, 양품률 = 양품 / 생산수.
  예: 부하 480분, 고장 25분, 셋업 35분 → 가동 420분, 가용률 87.5% / 이론 CT 1.0분, 생산 380개 → 90.5% / 양품 361 → 95.0% / OEE 75.2%.
- 6대 손실: 고장·셋업(가용률), 순간정지·속도 저하(성능효율), 공정 불량·초기 수율(양품률).
- 비가동 사유 대분류: 고장, 셋업, 자재 대기, 인원 부족, 품질 대기. 순간정지는 설비 신호로 자동 기록하고, 5분 이상 정지만 작업자가 사유를 입력한다.
- 성능효율이 100%를 넘으면 표준 CT 오류를 의심한다.
- 표시 형식: % 0.0, 정지 시간(min) 정수, 수량 #,0.
