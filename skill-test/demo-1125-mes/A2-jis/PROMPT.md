## 화면 요청
도어 트림 JIS 서열 출하 검증 프로그램. 프로젝트명 DoorTrimJisShipping.
목적: 공정 설비 프로그램(출하장 단말 한 대). 사용자: 출하 작업자 — 납입 대차 앞에서 바코드 스캐너로 부품 라벨을 스캔한다.
메인 화면: OEM 서열 수신 목록(서열 번호·차대번호·사양 코드(색상·스피커·좌우)·품번·투입 예정 시각·상태), 현재 대차 12칸의 칸별 할당 서열·스캔한 부품 품번·판정, 다음에 스캔할 칸 강조, 대차 출하 확정 버튼(모든 칸이 OK일 때만 누를 수 있음), 결번 알람, 납입 마감까지 남은 시간.
dialog: 서열 부품 대체(NG·결품 칸에 버퍼 재고 부품 시리얼 스캔, 대체 사유) — 대체 이력을 남기는 입력 폼.

## 도메인 정보 (MES 학습 경로 W09)
- JIS(Just In Sequence): OEM 라인 투입 순서 그대로 사양별 부품을 정렬해 납입한다. 서열 데이터: 서열 번호(연속, 결번 감지에 사용), 차대번호, 사양 코드, 투입 예정 시각, 상태(신규·변경·취소).
- 앞좌석 도어 트림: 색상 4종 × 스피커 2종 × 좌·우 = 16개 품번. 사양 코드 조합 → 품번은 사양 매핑 테이블로 정한다(품번 체계는 82307-AB100 같은 형식으로 정한다).
- 출하 검증: 대차 각 칸에 들어갈 서열 번호가 정해져 있고, 칸마다 부품 라벨을 스캔하면 "이 칸의 서열 사양과 부품 품번이 같은가", "순서가 맞는가"를 판정한다. 하나라도 틀리면 출하 확정이 되지 않는다.
- 결번: 수신한 서열 번호가 건너뛰면 즉시 알람(대차 칸이 비어 OEM 라인을 세울 수 있다).
- 사양 변경·취소: 생산 후면 다른 서열에 재할당하거나 재고로 돌린다.
- NG가 나면 같은 사양의 버퍼 재고로 대체하고, 서열 매핑 이력을 남긴다.
- 같은 시리얼 중복 출하는 차단한다.
- OEM 라인 정지 비용은 분 단위로 청구된다 — 납입 마감 시간이 가장 중요한 정보다.
