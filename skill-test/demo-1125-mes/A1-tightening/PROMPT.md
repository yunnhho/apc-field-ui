## 화면 요청
브레이크 캘리퍼 조립 체결 공정 스테이션 프로그램. 프로젝트명 CaliperTighteningStation.
목적: 공정 설비 프로그램(스테이션 한 곳 판정). 사용자: 조립 작업자 — 장갑, 바코드 스캐너, 스테이션 앞 모니터.
메인 화면: 제품 시리얼 스캔 → 인터락 판정(E01~E05 항목별 OK/NG와 사유) → 통과하면 볼트 4개 체결 진행(볼트별 순서·토크·각도·판정·시도 번호), 최종 OK/NG 큰 판정, 금일 생산·OK·NG, 최근 시리얼 체결 이력 표. 인터락 우회 중이면 화면에서 분명히 보이게 한다.
dialog: 인터락 우회 승인(관리자 비밀번호 확인 후: 우회 항목, 시간 범위, 사유).

## 도메인 정보 (MES 학습 경로 W09)
- 인터락 항목: E01 등록된 시리얼인가, E02 이전 공정이 OK로 완료됐나, E03 미해결 NG 이력이 없나, E04 투입 부품(캘리퍼 바디·브라켓 바코드)이 사양 BOM과 일치하나, E05 4M 변경 승인과 초품 합격이 끝났나. 판정 중 예외·DB 타임아웃은 E99 시스템 오류로 NG(fail-safe: 모르면 막는다).
- 판정 결과는 OK든 NG든 모두 기록한다(시리얼, 공정, 결과 코드, 판정 시각).
- 체결 결과 한 건: 툴 ID·채널(NR-05 CH1), Pset 번호, 볼트 순서(대각선 1-3-2-4), 최종 토크(하한 24.0 ~ 상한 27.0 N·m), 최종 각도(150 ~ 220°), 판정(OK / NG: 토크 낮음·각도 높음 등), 시도 번호. 정해진 순서와 다르게 체결하면 NG.
- 재체결: 같은 볼트 2회까지. 초과하면 시리얼 NG → 수리 공정으로.
- 인터락 우회: 권한자만, 항목·시간 범위 지정(예: E05만 2시간), 사유 필수. 우회 중 생산한 시리얼은 표식을 남기고 추가 검사 대상. 만료되면 자동 해제.
- 시리얼 예: 58210-AB100-261022-1-000123 (고객 품번 - 생산일자 - 라인 - 일련번호).
- 표시 형식: 토크 N·m 0.0, 각도 ° 정수.
