## 화면 요청
CNC 축 가공 공정 SPC 모니터링 프로그램. 프로젝트명 ShaftSpcMonitor.
목적: 공정 설비 프로그램(측정실 PC 한 대). 사용자: 공정 검사원 — 2시간마다 축 5개를 측정해 입력하고, 품질 엔지니어가 이상 여부를 확인한다.
메인 화면: 측정 항목 선택(축 지름 A, 축 지름 B, 전장), 선택 항목의 X̄ 관리도·R 관리도 추이(최근 25부분군, UCL/CL/LCL), 현재 X̄·R·Cpk·Ppk 카드, 이상 규칙 위반 이력 표(시각·항목·규칙·내용·조치), 다음 측정 예정 시각.
dialog: 부분군 측정값 입력(값 5개, 입력하는 대로 X̄·R 표시, 규격을 벗어난 값은 경고).

## 도메인 정보 (MES 학습 경로 W07)
- 축 지름 A: 규격 25.000 ± 0.300 mm (LSL 24.700, USL 25.300). 관리 한계(Phase I에서 고정): X̿ 25.000, R̄ 0.200, n = 5 → X̄ UCL 25.115 / LCL 24.885, R UCL 0.423 / LCL 0. σ̂ = R̄ / d₂ = 0.200 / 2.326 = 0.086.
- 관리 한계는 규격 한계가 아니다. 화면에서 둘을 구분해 보여 준다.
- Cp = (USL − LSL) / 6σwithin, Cpk = min(USL − μ, μ − LSL) / 3σwithin. Pp·Ppk는 전체 표준편차로 같은 식. Cpk 1.33 이상 양호, 1.00~1.33 주의, 1.00 미만 부족.
- 이상 판정 규칙(1~5 사용): 1) 1점이 3σ 밖 2) 연속 3점 중 2점이 같은 쪽 2σ 밖 3) 연속 5점 중 4점이 같은 쪽 1σ 밖 4) 중심선 한쪽에 연속 8점 5) 연속 6점 증가 또는 감소(공구 마모).
- Phase II에서는 한계를 매번 다시 계산하지 않는다(4M 변경 승인 후에만 재설정).
- 이탈 시 OCAP: 알람 → 측정 재확인 → 설비 점검 → 판정 → 기록.
- 표시 형식: mm 0.000(규격 ±0.300, 한계 25.115 때문에 스킬 기본 0.00 대신 이 요구서를 따른다), Cpk·Ppk 0.00.
